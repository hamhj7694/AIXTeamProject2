# 사용 범위

실제 송금·이체 피해가 확인된 상황에서 피해구제 신청, 사기이용계좌 지급정지, 채권소멸·피해환급 제도의 법적 근거를 확인하는 데 사용한다.

# 공식 Knowledge

## 피해구제 신청과 지급정지의 법적 근거

현재 시행본 제3조는 전기통신금융사기로 피해를 입은 사람이 금융회사에 피해구제를 신청할 수 있도록 정한다. 제4조는 피해구제 신청 또는 지급정지 요청 등이 있고 거래내역 확인을 통해 사기이용계좌로 의심할 사정이 인정되는 경우, 금융회사가 해당 사기이용계좌 전부에 지급정지 조치를 하도록 정한다.

## 채권소멸절차와 피해환급 제도

현재 시행본은 사기이용계좌 채권의 소멸절차와 피해환급절차를 전기통신금융사기 피해자의 재산상 피해 회복을 위한 제도로 둔다. 제10조는 채권 소멸 뒤 금융감독원이 피해환급금을 받을 사람과 금액을 결정·통지하고, 통지를 받은 금융회사가 이를 지급하도록 정한다.

# 주의 / 적용 한계

- 이 법령은 개별 Case의 사기이용계좌 해당성, 지급정지 가능 여부, 피해구제·환급 적용 여부를 자동으로 결론내리지 않는다.
- 실제 송금 완료 또는 실제 피해가 확인된 Runtime Case State에서만 관련 절차 검토의 근거로 사용한다. 송금 요구만으로 적용하지 않는다.
- 거래 금융회사별 접수 경로·필요 서류는 이 법령에 없으므로 Q03은 PARTIAL이다.
- 2026-10-01 시행 예정인 일부 개정 조항은 현재 시행 지침처럼 사용하지 않는다.
