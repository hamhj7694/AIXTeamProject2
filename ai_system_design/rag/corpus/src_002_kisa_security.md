# 사용 범위

문자·피싱사이트를 통한 악성앱 설치 유도, 원격제어앱 요구, 아이디·비밀번호·인증번호 입력 주의, 실제 악성앱 설치 또는 금융정보 유출 의심 시의 공식 대응 확인에 사용한다.

# 공식 Knowledge

## 원격제어앱 설치 요구는 공식 기관·금융회사 방식이 아님

KISA는 정부기관 및 금융회사가 전화나 문자로 원격제어앱 설치를 요구하지 않는다고 안내한다. 정상 앱 스토어에 등록된 앱도 포함된다. 기관·금융회사를 사칭한 연락이 원격제어앱 설치를 요구한 경우, 그 요구를 공식 절차로 취급하지 않고 사칭·보안 위험 확인의 근거로 사용한다.

## 악성앱 설치 유도와 실제 설치 후 점검

KISA는 출처가 불분명한 문자 속 사이트 주소를 클릭하지 말고 삭제하며, 의심 주소는 정상 사이트와 일치하는지 확인하도록 안내한다. 문자 속 인터넷주소를 클릭한 사실만으로 악성앱 감염을 단정하지는 않는다. 다만 해당 주소를 통해 앱을 설치했다면 모바일 백신 점검·삭제, 수동 삭제, 서비스센터 방문 방법으로 스마트폰 점검을 안내한다.

## 인증·계정정보 입력 및 금융정보 유출 의심 시 대응

휴대폰번호·아이디·비밀번호 등 개인정보는 신뢰된 사이트에만 입력하고, 인증번호는 모바일 결제와 연계될 수 있어 추가 확인이 필요하다고 안내한다. 악성앱에 감염된 스마트폰으로 금융서비스를 이용한 경우에는 금융거래에 필요한 정보가 유출될 가능성이 있으므로 해당 정보를 폐기하고 재발급하도록 안내한다.
