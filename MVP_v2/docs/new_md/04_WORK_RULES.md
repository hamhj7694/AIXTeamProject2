# MVP_v2 작업 규칙

- 상위 PRD와 `05_DATA_SCHEMA_AND_FLOW.md`를 먼저 읽는다.
- 데이터 필드 변경은 계약 → 저장소 → API → Frontend → 테스트 → 문서 순으로 반영한다.
- 고객에게 BANK_INTERNAL·AI_INTERNAL·내부 검증 근거·위험 점수를 노출하지 않는다.
- AI는 DB 직접 수정·승인 없는 고객 발송·외부 기관 자동 요청을 하지 않는다.
- 확인되지 않은 값은 `확인안됨`으로 표시하고 추정하지 않는다.
- 기능 카드는 초안 → 실행 완료 → 대상 채널 전달 상태를 채팅에 남긴다.
- 개인 메모는 `private-to-author`가 기본이며 명시적 전환 전에는 다른 사용자·AI·고객에게 노출하지 않는다.
- 북마크는 원본 Message/Card를 수정하지 않는 개인 바로가기이며, 원본 삭제·권한 변경 시 접근권한을 다시 확인한다.
- 고객 발송, Fact 확정, BankAction, 상태 변경은 사람의 명시적 승인/확정 액션 없이는 실행하지 않는다.
- 모든 완료 작업은 빌드/테스트/수동 경로를 기록한다.
- 로컬 Frontend는 `dist` 없이 Vite 개발 서버로 실행하고 `/api/*`를 General API로 프록시한다. Frontend가 AI API를 직접 호출하지 않는다.
- `dist`, `.vite`, 실행 로그는 생성 산출물이며 Git에 포함하지 않는다.
- 현재 MVP에서 음성 통화·녹음·실시간 STT 기능을 새로 연결하거나 활성 화면에 노출하지 않는다. 별도 후속 PRD 승인 전까지 구형 voice 구현은 정리 대상이며 재도입하지 않는다.
- 첨부 원본 경로는 서버 내부 값이며 API/Frontend에 노출하지 않는다. 첨부의 공개 범위는 연결 메시지의 공개 범위와 일치해야 한다.
- AI는 권한이 허용된 첨부만 읽고, 파싱되지 않은 파일 내용을 추정하지 않는다.
