# MVP_v2 PRD 요약

의심 통화를 문장별 ML과 전체 맥락으로 분석하고, 임계값 이상이면 하나의 Case를 생성한다. 고객·은행·검증 담당자·AI가 같은 Case를 역할별 공개 범위에서 상담·질문·검증·보호조치·보고로 이어간다. 탐지 정확도보다 탐지 이후의 정보수집·사건맥락 재구성·고객 설득·업무 인수인계를 하나의 Case에서 연결하는 것을 핵심 가치로 둔다.

최종 화면은 Case 목록, Case 개요, 고객 상담, 은행 대응, 기관 검증이다. 고객은 진행 스테퍼·고정 피해구제 메뉴·질문 카드를 보고, 은행은 내부 협업·고객 대화·AI 개인 작업공간과 사건 진행 타임라인을 사용한다. AI 제안은 사람 승인 전까지 후보이며 외부 기관·금융거래를 자동 실행하지 않는다.

## Chat-first 원칙

채팅은 단순 상담창이 아니라 조회·질문·검증·Fact·조치·상태변경·공유가 시작되는 기본 작업 인터페이스다. 다만 Case 목록, Timeline, 진행 스테퍼, 개인 메모, 북마크, 보고서는 계속 확인해야 하는 보조 UI로 제공한다. 모든 상호작용은 Message, Question, CaseFact, Verification, BankAction, Bookmark, PersonalNote, Event 같은 구조화 객체로 저장한다.

## 신규 필수 기능

- 은행 담당자의 Case별 개인 메모: 작성자 본인만 보는 자동저장 메모이며 필요할 때만 내부 공유 또는 Fact 후보로 전환한다.
- 메시지/카드 북마크: Case별 바로가기 목록에서 원본 채널·메시지로 이동하고 강조 표시한다.
- Recovery Mode: 피해 발생 시 기존 Case의 맥락·근거·Timeline을 재사용해 지급정지·신고·피해구제·기기/계정보호 업무를 이어간다.

상세 요구사항과 비목표는 상위 PRD를 기준으로 한다.
