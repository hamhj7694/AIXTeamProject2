[수정 사항]

1. 고객화면
- 새로 만들어진 캐이스에서 고객 채팅에서 AI가 호출 안되고 있음.
- 고객에게 보이는 질문 카드는 응답하기 전까지는 항상 채팅창 가장 아래에 있어야 함! 다른 채팅을 쳐도 올라가지 않도록 해야함.
- 채팅이나 질문 카드에 대한 답변들을 AI가 인식해서 관련된 함수도 호출 되어야함
(예시 : 채팅창에서 '이미 송금했어' 입력하거나, 질문 카드 응답에서 '이미 송금했어요' 등 응답하면 --> [이미 사기 당했어요] 버튼에 대한 함수 발동
-AI 조언 요청했으나 고객에게 조언 요청이 가지 않고 있음.

+ AI 펑션 추가(후순위)

---
2. 은행화면
- 채팅창에 [AI에게 물어보기] 버튼 추가하자 : 이거 활성화하고 채팅치면 AI가 호출돼야 해(고객에게는 안 보이지만, 은행 내부에는 해당 AI의 출력 결과가 보여야함)
- [고객에게 확인 질문] 안에 [AI에게 질문 추천 받기] 버튼 및 기능 추가해줘!
('고객에게 확인 질문' 창에서 질문을 적고 있는 도중에 전체적으로 입력 포커스가 풀리는데... 내가보기에 전체적으로 화면을 리로드 되기 때문에 여러 기능들이 작동 되다가 멈추거나 그런게 아닐까 싶어! 이런 문제는 어디에서도 생기면 안되니까 종합적으로 점검 및 수정해줘!)
- 사건 정리 기능 AI 정상 작동되도록 해줘!
- [기관 확인 요청] 창에서 바로 '기관 확인 요청'하지 않고 '기관 확인 리스트'로 작용하게 해줘! 여기에도 [AI에게 추천 qk받기] 기능이 있으면 좋겠어! 이걸 사용하면 AI가 현재 사건 캐이스의 모든 내용들을 검토하고, 어디를 어떤 주장으로 사칭하고 있는지 조사해서 추천 초안을 작성해주는거야. 은행 직원은 이걸 보고 필요하면 텍스트 수정할 수 있어.(검찰 사칭이면 공식 검사에게 문의할 수 있는 연락처 같은걸 입력 받을 수도 있는거고!)


---
프론트 엔드에서 그려져야 하는 것중 AI가 그려야 하는 것들도 실시간으로 잘 반영돼야해!
특히 은행 화면의 [CASE CONTEXT 사건 맥락] 에 있는 context-scroll 영역에 그려지는 데이터들에 변동이 생기면 AI가 최신 사항을 반영할 수 있어야해. 예를 들면, '확인 필요 사항' 부분도 실제 요청된 질문이나, 회신 온 답변 카드에 따라 내용이 바뀌기도 해야해!

---/
아래 요청을 순서대로 수행해줘.
- 은행 화면에서 [AI에게 물어보기전송 후 답변이 은행 내부에만 표시됩니다.]  버튼 위치는 target-toggle  왼쪽 끝에 있으면 좋겠어!
- 그리고, 은행 화면 > 사건 맥락 안에 [확인 필요 사항] 부분에는 기존에 확인된 사항이 기록되는게 아니고, 앞을고 확인해야하거나... 미래의 절차 등을 정리하는 거야!
- 확인 필요 사항, 권장 조치... 이 2가지가 각각 어떤 역할인지 알려줘!

---
질문 카드 생성은 은행 직원이 하지 않아도, AI가 자동으로 선재적으로 만들어서 고객에게 주도적으로 질문하면 좋겠어! 고객이나 은행 직원의 요청이 없어도 말이야!
다만, 모든 질문을 AI가 항상 독단적으로 하면 안되고, 아주 필수적이고 중요하고 긴급성 있는 질문들을 우선순위로 AI가 자동 독단적으로 고객에게 질문 카드로 만들어서 발송하는 건 괜찮아!
---

비슷한 요청일 수 있지만, [은행 - 중앙(DB) - 고객] 전반에서 데이터 변동사항이 있으면 실시간으로 반영될 수 있게 해야해. 어떤 공간에서라도 인풋이 있으면 db의 데이터를 업데이트해야할지 판단하고 db에 저장하고, 그걸 프론트에서 그릴 수 있어야 하는거야!

그러고 그거에 맞게 명칭이나 UI/UX 그리고 기능들도 변경해줘!
