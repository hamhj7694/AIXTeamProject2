## 사용 규칙

1. 기존 문서는 현재 구현과 과거 계약을 이해할 때만 참고한다.
2. 새 프론트엔드 화면 요구와 충돌하면 상위 폴더의 새 설계를 우선한다.
3. 기존 API를 새 화면에 맞추기 위해 임의로 의미를 재해석하지 않는다.
4. 새 API 계약이 승인되기 전에는 기존 계약 파일을 수정하지 않는다.
