# 기존 문서 보관 기준

기존 `MVP_v3/docs/*.md` 문서는 현재 구현·계약의 이력과 회귀 기준으로 사용되므로 원래 경로를 유지합니다.

이 폴더는 기존 문서를 임의로 복제하거나 이동하지 않고, 구 문서와 새 기준 문서를 구분하기 위한 보관 영역입니다.

- 최신 구현 상태: [`../CURRENT_STATUS.md`](../CURRENT_STATUS.md)
- 현재 실행 계획: [`../now_md/README.md`](../now_md/README.md)
- 과거 문서의 정확한 이력: Git history

문서 이동이 필요한 경우에는 상대 링크와 `CURRENT_STATUS.md` 참조를 함께 갱신하는 별도 작업으로 진행합니다.
