# 사건 종결 AI 보고서 계약

최종 갱신: 2026-09-05

## 1. 목적

사건 종결 보고서는 최신 Shared Case에 저장된 사실·고객 진술·기관 확인·담당자 조치와 담당자의 종결 메모를 AI가 종합해 작성하는 **은행 내부 업무 문서**다. AI는 보고서를 작성하지만 종결 결정과 보고서 승인 책임은 은행 직원에게 있다.

## 2. 생성 원칙

- 사건 종결 요청 시점에 한 번 생성한다.
- 고객 진술과 은행·기관이 확인한 사실을 구분한다.
- 지급정지, 피해구제, 신고 등은 완료 근거가 있을 때만 완료로 쓴다.
- 근거가 없거나 확인하지 못한 내용은 추정하지 않고 `남은 미확인 사항`에 기록한다.
- 내부 변수명·코드명·모델 점수·프롬프트는 출력하지 않는다.
- AI 연결이나 생성이 실패하면 임의 보고서를 만들거나 사건을 종결하지 않고 명시적 오류를 반환한다.
- 저장된 최종 보고서를 화면 카드, PDF, Word가 공통 원본으로 사용한다.
- 고객 화면에는 최종 내부 보고서 원문을 공개하지 않는다.

## 3. 문서 구조

| 순서 | 영역 | 형식 | 역할 |
|---|---|---|---|
| 1 | 제목 | 한 줄 | 사건을 식별할 수 있는 보고서 제목 |
| 2 | 종합 요약 | 2~4개 짧은 문장 | 사건·피해·처리·종결 상태를 빠르게 파악 |
| 3 | 사건 개요 | 짧은 문단 | 사칭 주체, 주장, 요구 및 사건 흐름 |
| 4 | 고객 피해·노출 상태 | 짧은 문단 | 송금 피해와 개인정보·인증정보 노출 상태 |
| 5 | 확인된 사실 | 개조식 | 담당자 또는 공식 근거로 확인된 사실 |
| 6 | 기관 확인 결과 | 개조식 | 기관별 확인 요청 및 회신 결과 |
| 7 | 대응 및 처리 내역 | 개조식 | 실제 수행한 은행 업무와 고객 안내 |
| 8 | 남은 미확인 사항 | 개조식 | 종결 시점에도 확인되지 않은 항목 |
| 9 | 종결 판단 근거 | 개조식 | 담당자가 종결을 승인할 수 있는 근거 |
| 10 | 최종 처리 결과 | 짧은 문단 | 담당자 종결 메모를 반영한 결론 |
| 11 | 후속 업무 | 개조식 | 종결 후 추적·연락·보존이 필요한 업무 |
| 12 | 유의사항 | 개조식 | 오인 가능성, 제한 사항 및 주의점 |

## 4. 데이터 계약

AI 출력 필드는 다음과 같다.

```text
title: string
executive_summary: string
incident_summary: string
customer_impact_summary: string
verified_facts: string[]
verification_results: string[]
actions_taken: string[]
unresolved_items: string[]
decision_basis: string[]
resolution: string
follow_up: string[]
cautions: string[]
```

General API는 이를 12개의 `section_key`로 나누어 FINAL 보고서에 저장한다. 은행용 Case bundle은 종결된 사건의 최신 FINAL 보고서를 `final_report`로 반환하며, Frontend는 임시 채팅 JSON이 아니라 이 저장 보고서를 기준으로 문서 카드를 그린다.

## 5. 화면과 내보내기

- 은행 채팅 Timeline에서 종결 시각에 문서형 카드로 표시한다.
- 카드에는 모든 보고서 영역과 보고서 버전을 표시한다.
- PDF와 Word 다운로드는 같은 저장 보고서를 사용한다.
- 과거 형식 보고서는 가능한 기존 section을 새 카드 영역으로 변환해 표시한다.
- 변환할 수 없는 과거 채팅 카드가 있더라도 `보고서 내용을 표시할 수 없습니다`라는 빈 카드 대신 안전한 문서 안내 형태로 표시한다.

## 6. 완료 조건

- AI 보고서 JSON schema 검증 통과
- 보고서와 사건 종결의 DB 트랜잭션 저장
- 새로고침 후 동일 보고서 카드 유지
- PDF·Word가 화면 카드와 같은 저장 원본을 사용
- 은행 bundle에는 표시되고 고객 bundle에는 노출되지 않음
- AI 장애 시 가짜 보고서와 거짓 종결이 발생하지 않음
